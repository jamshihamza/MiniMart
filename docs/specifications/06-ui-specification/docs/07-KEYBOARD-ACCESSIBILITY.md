# 07 --- Keyboard & Accessibility

-   Full POS core flow must be completable without mouse.
-   Visible focus indicators are mandatory.
-   Logical tab order follows task order.
-   Dialogs trap focus and restore it on close.
-   Screen-reader names exist for icon-only controls.
-   Error messages identify the field and corrective action.
-   Status is not encoded by color alone.
-   Text zoom and Windows display scaling must not hide primary actions.
-   Numeric input supports locale presentation while preserving
    canonical decimal contract values.
-   Reduced-motion preference is respected for nonessential animation.
