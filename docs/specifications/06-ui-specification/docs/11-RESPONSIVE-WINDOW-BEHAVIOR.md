# 11 --- Window & Responsive Behavior

MiniMart is desktop-first.

-   POS target: 1366×768 and above; minimum validation target 1280×720.
-   Back Office target: 1366×768 and above.
-   Cloud Web may adapt to tablet widths for read/management work.
-   Core POS posting is not designed as a phone workflow in v1.
-   At smaller supported widths, secondary panels collapse to drawers;
    primary totals/payment actions remain visible.
-   No horizontal page scrolling for the POS sale workspace.
