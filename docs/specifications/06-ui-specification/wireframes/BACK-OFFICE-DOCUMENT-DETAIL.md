# Back Office Posted Document Pattern

``` text
┌─────────────────────────────────────────────────────────────────────┐
│ Document No · POSTED         Business Date · Rule Version          │
│ Historical Party / Store Snapshot                [Corrective Action]│
├─────────────────────────────────────────────────────────────────────┤
│ Lines / values / taxes / totals — READ ONLY                         │
├─────────────────────────────────────────────────────────────────────┤
│ Related stock / tender / credit / financial effects                │
│ Audit metadata                                                     │
└─────────────────────────────────────────────────────────────────────┘
```

No "Edit" action is shown for posted financial/stock facts.
