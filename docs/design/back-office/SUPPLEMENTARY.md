# Back Office supplementary reference documentation

These exported index/group pages are unapproved supplementary reference/proposal
material. They do not inherit approval from a source or from another package.
Frozen specifications, the Decision Register and backlog remain functional
authority; the existing package manifest remains unchanged.

The original export files are retained in the Office PC's protected `Mockups/`
set. `supplementary-provenance.json` records their original byte hashes and every
candidate adjustment. Existing `source/MiniMartBackOffice.dc.html` is reused;
no design source or runtime is duplicated.

The grouped pages reuse the existing Procurement `support.js` through a relative
link. This is the genuine runtime already tracked in the repository, not a new
implementation. Missing `image-slot.js` remains a fidelity gap. Availability of a
page or an artboard is not evidence of complete or approved visual fidelity.

Authority review pointers: UI `04-BACK-OFFICE-EXPERIENCE`,
`15-OPEN-UI-DECISIONS`; FRS `FR-CAT-002`, `006`-`008`, `022`-`025`,
`034`-`038`, `046`-`048`; Catalog/Pricing ownership remains as frozen.
Exact skeleton fields, import policy, duplicate matching, pricing thresholds,
bulk approval and shortcut decisions are not resolved by these pages.

Historical responsiveness claims in exported documentation are design claims,
not fresh validation results. See the accompanying validation notes before any
checkpoint. Existing approved sources, manifests and historical fidelity report
must not be modified by this supplementary preservation.

## Validation observed

On 2026-10-03, all seven supplementary scripts parsed/evaluated and booted on
the existing genuine runtime in Chrome at 1366x768. Six grouped pages imported
the existing Back Office source; there were no page errors, runtime logic errors
or unresolved expressions. The index's POS cross-link is satisfied by the
separately preserved POS wrapper; all eight index links and six return links
resolve in the combined candidate worktree.

Each grouped page inherits a request for missing `image-slot.js` from the
unchanged Back Office source. Create/Edit, Detail/Skeleton and Design System
groups also contain undefined `image-slot` elements. Full fidelity is therefore
incomplete. No adapter or replacement has been created. Genuine fonts/icons
were reused from the existing cache or fetched in memory; original cache files
were not changed. Screenshots remain temporary diagnostic outputs.

Documentation claims about other viewports are historical design claims; this
preservation pass does not re-approve them. The candidate is an unapproved
supplementary-reference checkpoint proposal, with the runtime gap disclosed.
The POS Design System wording conflict was corrected under explicit owner
direction; see that package's review notes. The Back Office index's POS wrapper
cross-link is an explicit checkpoint dependency: include the POS supplementary
group first or in the same checkpoint. Neither package's status is promoted.
