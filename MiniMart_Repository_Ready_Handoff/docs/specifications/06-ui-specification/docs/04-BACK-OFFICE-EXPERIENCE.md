# 04 --- Back Office Experience

Back Office is optimized for 1366×768 and larger Windows workstations,
while remaining usable at 1280×720.

## Page pattern

Each module uses: 1. Page header with title/status/context. 2. Primary
action. 3. Search/filter bar. 4. Data grid or task content. 5. Detail
route/drawer. 6. Audit/history panel where relevant.

## Draft versus posted documents

Draft documents may expose editable controls according to permissions
and frozen domain rules. Posted documents use a read-only document
viewer with corrective actions such as Return, Reverse, Refund, Reprint
or Create Follow-up where the relevant contract permits them.

## Dashboards

Dashboards are operational, not decorative. Every card must answer one
of: - what needs attention? - what happened? - what can I do next?

Avoid vanity metrics with no operational use.
