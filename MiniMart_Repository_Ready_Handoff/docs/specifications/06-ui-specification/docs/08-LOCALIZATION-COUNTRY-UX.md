# 08 --- Localization & Country UX

The core UI is country-neutral. Country-specific fields and actions
appear through active capabilities/rule-set versions rather than country
forks.

Posted documents display the country-rule version and historical
snapshots needed for faithful reprint/history. Historical receipts must
not be re-rendered using current master defaults.

Malaysia is the first target and India follows. Current statutory
labels, invoice requirements and tax behavior are
implementation/compliance verification inputs, not assumptions to be
invented in the UI specification.
