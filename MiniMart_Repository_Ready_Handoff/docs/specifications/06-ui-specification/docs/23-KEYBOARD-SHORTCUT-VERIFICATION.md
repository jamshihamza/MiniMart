# 23 --- Keyboard Shortcut Verification

The v0.1 shortcut proposal remains **PROVISIONAL until Phase 0
Windows/hardware conflict testing**.

Candidate POS shortcuts: F2 Search, F4 Customer, F6 Hold/Recall, F8
Payment, F9 Cash when permitted, F10 contextual confirm, Esc close
transient surface.

Freeze rule: UI semantics do not depend on a particular function key.
Every shortcut has a visible/clickable equivalent. Phase 0 may remap
keys without changing business behavior, but the final implemented map
must be documented and tested against scanner/printer/vendor utilities.
