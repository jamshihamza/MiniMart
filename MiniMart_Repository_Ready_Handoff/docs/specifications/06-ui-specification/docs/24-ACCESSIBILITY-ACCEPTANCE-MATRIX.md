# 24 --- Accessibility Acceptance Matrix

Critical workflows --- Sign in, POS sale, payment, payment recovery,
return/refund, shift close, GRN posting, stock count posting, supplier
payment and manager override --- must pass:

-   keyboard-only completion;
-   visible focus at every actionable element;
-   logical focus order;
-   dialog focus trap/restore;
-   accessible name for icon-only actions;
-   errors associated with fields plus summary for long forms;
-   status communicated by text/icon, not color alone;
-   1280×720 usability where POS/Back Office supported;
-   Windows display scaling verification;
-   reduced-motion preference for nonessential motion.
