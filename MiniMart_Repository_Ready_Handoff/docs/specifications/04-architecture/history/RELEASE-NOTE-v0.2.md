# MiniMart Architecture Refinement v0.2 --- Release Note

v0.2 is the Architecture Freeze Candidate.

Compared with v0.1, it adds freeze-grade contracts for provider
uncertainty/reconciliation, UnitOfWork persistence capability, Store
Node trust/session, sync ownership/application, rolling compatibility,
read/query separation, BusinessContext resolution, worker leasing, DB
runtime policy, audit/telemetry separation, hardware lifecycle,
configuration ownership, support isolation, Store/Cloud capability
composition and reconciliation/rebuild ownership.

All findings from the Deep Architecture Consistency Review are
remediated. No unresolved product/compliance Decision has been silently
resolved.
