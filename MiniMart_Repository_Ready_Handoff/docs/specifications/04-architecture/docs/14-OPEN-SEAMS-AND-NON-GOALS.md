# Open Seams and Non-Goals --- v0.3

The exact 60 frozen Decision IDs are enumerated in the Architecture
Decision-Seam Matrix. v0.3 provides architecture extension points but
does not resolve them.

Legacy unnumbered seams also remain explicit: item-code generation;
skeleton-item rules; UoM/weighted barcode depth; category hierarchy;
credential/session values; delegated permission/override authentication;
supplier numbering/duplicate heuristics; pricing maker-checker/minimum
margin; label hardware/workflow; counter enrollment/licensing limits;
later multi-currency.

Non-goals remain: - microservices; - synchronous cloud billing; -
Phase-1 SQLite survival; - choosing payment/e-invoice/hardware/support
providers; - hard-coding current Malaysia/India legal values; - freezing
endpoint URLs or UI screens in the architecture stage.
