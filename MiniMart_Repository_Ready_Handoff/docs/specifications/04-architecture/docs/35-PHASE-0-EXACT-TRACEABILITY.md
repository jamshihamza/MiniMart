# Phase-0 Exact Traceability --- v1.0 FROZEN

## Sync engine evaluation

The minimal real-sync spike records **sync engine evaluation evidence**
against the approved custom Outbox/Inbox change-feed design. A proposed
replacement requires an ADR and must preserve ownership, idempotency,
inbox deduplication, outbox, ACK/retry and offline-first semantics.

## Malayalam and Malay receipt verification

Where these scripts are in pilot scope, the exact pilot receipt printer
is tested using rasterized **Malayalam and Malay** receipt content.
Evidence covers readability, width/layout, print speed, cut behavior and
fallback/error handling.
