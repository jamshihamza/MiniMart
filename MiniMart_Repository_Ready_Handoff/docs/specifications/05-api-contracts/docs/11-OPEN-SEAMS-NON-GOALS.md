# Open Seams and Non-Goals

This API baseline does not choose PO/direct-GRN policy,
supplier-reference duplicate policy, over-receipt policy, PO approval,
stock-count concurrency algorithm, batch/FEFO, reorder ownership,
BusinessDate rollover, document-number scope, held-sale repricing,
active-sale repricing, expired-stock sale, payment provider, permanent
manual/integrated card/QR mode, cash-rounding value, surcharge,
no-receipt return, exact disposition vocabulary, refund
allocation/substitution, tax reversal,
credit-limit/allocation/advance/suspension/held-exposure policy,
business-day/shift policy, report grouping, import
retention/opening-stock migration, audit/log retention, hardware
protocol/fallback, backup RPO/RTO/retention/provider, remote-support
provider, or current Malaysia/India legal values.

Non-goals: production server code, UI screens, provider SDK selection,
cloud checkout, microservices, Phase-1 SQLite survival, new reporting
tables/projections, or changing frozen ownership.
